The 12 topics in the guide.

Every topic follows the same format: the risk, an example, how to check, how to fix.

  1. Keep secrets and API keys out of your code
  2. Lock down access to your database
  3. Check who may open every page and API route
  4. Validate input and block injection
  5. Check your dependencies, including ones that may not exist
  6. Verify payments and webhooks on the server
  7. Limit abuse with rate limits and spending caps
  8. Keep useful logs and tested backups
  9. Separate development from production
  10. Handle personal information responsibly
  11. If your app uses an AI model, defend against prompt injection
  12. Get an independent review before launch
